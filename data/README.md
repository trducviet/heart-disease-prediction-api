# Dataset

Place a de-identified CSV named `heart.csv` in this directory before running `python train.py`.

The training workflow expects the columns:

`Age, Sex, ChestPainType, RestingBP, Cholesterol, FastingBS, RestingECG, MaxHR, ExerciseAngina, Oldpeak, ST_Slope, HeartDisease`

The dataset is excluded from this repository to keep data provenance and handling explicit.
